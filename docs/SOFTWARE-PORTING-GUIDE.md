# VeridianOS Software Porting Guide (superseded)

This guide described the native `<arch>-veridian` target triples and the pre-ADR-0009 system
call numbering, neither of which applies to porting software today. The current guide is
[PORTING-GUIDE.md](PORTING-GUIDE.md): the musl toolchains, autotools/CMake/Meson setup,
getting a program onto a root image, what differs from Linux, credentials, the uname mode and
the Portfiles. The old text is in git history.
