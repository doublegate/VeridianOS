# Linux / POSIX Compatibility Plan

- Status: planned (v0.27 - v0.31)
- Date: 2026-10-06
- Baseline: [`LINUX-SYSCALL-COVERAGE.md`](LINUX-SYSCALL-COVERAGE.md), generated by
  `tools/compat/syscall_coverage.py` from Linux v7.2 `arch/x86/entry/syscalls/syscall_64.tbl`

## Goal and definition of done

POSIX.1-2024 (IEEE 1003.1-2024 / Open Group Base Specifications Issue 8) is a *source-level* standard
covering the libc API, kernel semantics, the shell and utilities. Running standard Linux applications
needs more than that: **Linux binary-ABI compatibility**, the approach of gVisor, WSL1 and FreeBSD's
Linuxulator, with musl or glibc providing the POSIX API.

The work is done when all of the following hold:

- **Every syscall accounted for.** Every native syscall of the latest stable Linux is either
  implemented with Linux semantics or returns exactly what Linux returns. That is 385 on x86_64 in
  Linux 7.2, and about 325 in the generic table that arm64 and riscv use. Linux returns ENOSYS for
  16 of the x86_64 numbers itself.
- **Conformance suites in CI.** LTP `syscalls`, LTP `open_posix_testsuite` and musl `libc-test`
  run in CI with pass counts tracked. The gate is "no regressions", and the counts ratchet upward.
- **An application ladder runs unmodified.** In order:
  1. BusyBox
  2. toybox
  3. static GNU coreutils and bash
  4. dynamic musl (the Alpine userland and `apk`)
  5. dynamic glibc (Debian binaries)
  6. python, git, gcc, openssh, nginx

Formal Open Group certification (VSX-PCTS) is out of scope, because it uses a commercial test suite.

User mode exists on x86_64 only. The native IPC syscalls 0-7 cannot be reached from user programs
(audit N-33).

## X0. Prerequisites (v0.27)

1. **Process model (C5)**
   - User processes and threads become scheduler-dispatched, preemptible tasks in ring 3, EL0 or
     U-mode.
   - Each thread gets a kernel stack with a guard page (N-26).
   - User threads: `clone` with `CLONE_VM|CLONE_THREAD|CLONE_SETTLS|CLONE_*TID`.
   - Any syscall can block voluntarily.
2. **AArch64 MMU and caches on (N-28)**
   - Set up TCR, MAIR, TTBR0 and TTBR1.
   - Retire `fs::bare_lock` in favour of real locks.
   - Add EL0 entry and exit, and SVC dispatch.
3. **RISC-V U-mode:** Sv48 user page tables, `ecall` dispatch, and a kernel-stack switch through
   `sscratch`.
4. **Memory and CPUs:** SMP bring-up, TLB shootdown, and copy-on-write fork.

## X1. One user ABI (done in v0.27, ADR 0009)

- **Linux numbering.** Done for x86_64: the numbers come from `abi/linux/syscall_64.tbl` through
  `abi/syscalls.map` and `tools/compat/gen_syscalls.py`, which generates the kernel enum, the C
  and Rust constants and `SYSCALL-NUMBERS.md`, checked in CI. arm64 and riscv64 get Linux's
  generic table with their user mode (sprint E).
- **VeridianOS calls in their own range.** Done: private numbers from 1024; N-33 fixed.
- **One libc path.** Done: the native numbering and the musl remap patch are retired; musl is
  built stock. Every program built before must be rebuilt.
- **Linux semantics behind Linux numbers.** A review of every handler found about 80
  differences (`docs/audit/ABI-REVIEW-2026-10-07.md`, N-182 to N-250). The ones the switch
  exposed are fixed; the rest are scheduled into the X2 groups below and sprints D and F.
- **One errno table,** shared by the kernel and libc: open (C3). Errors already reach every
  caller as Linux errno values.

## X2. Syscall completion (v0.28 - v0.31)

Each group lands with its LTP cases. The counts are "missing" entries in the coverage table.

- **process (37)**
  - vfork, waitid, getpgid/getsid
  - the uid/gid family
  - capget/capset, times, personality, getcpu
  - priority and rlimit calls
  - pidfd_*, kcmp, process_vm_*, ptrace
  - unshare/setns
  - real prctl, rseq
- **signals (11)**
  - The pending/timedwait/suspend/queueinfo family, tkill/tgkill, pause, alarm, itimers,
    restart_syscall, and a real sigaltstack.
  - Semantics to get right: delivery on every return to user mode, SA_RESTART versus EINTR, queued
    realtime signals, per-thread masks, core dumps and job-control stops.
- **time (14)**
  - Settable and adjustable clocks, POSIX timers, and the utime family.
  - CLOCK_REALTIME from the RTC epoch, every clock ID, and nanosecond file timestamps.
- **files (55)**
  - truncate, fchdir, creat, lchown, getdents, mknodat, readahead/fadvise and the sync family.
  - Locks: flock, POSIX record locks and OFD locks.
  - sendfile, splice/tee/vmsplice and copy_file_range.
  - Vectored I/O, renameat2 and openat2, close_range and fchmodat2, and execveat.
  - Handles, xattrs, inotify and fanotify.
  - Real statx/statfs/fallocate, and every O_* flag.
- **memory (23)**
  - msync, mincore, the mlock family, real mremap, pkeys, mseal, membarrier and userfaultfd, plus
    the NUMA calls.
  - A page cache, so shared file mappings stay coherent.
  - Enforced mprotect.
- **ipc (22):** SysV shm/sem/msg, POSIX mqueues, and futex2.
- **events (14):** the epoll variants, pselect6, eventfd, signalfd, Linux AIO and io_uring.
- **network (3) plus the stack**
  - shutdown, recvmmsg and sendmmsg.
  - Complete TCP (NET-INC-01, N-20).
  - AF_UNIX datagram and seqpacket sockets, the abstract namespace, SCM_CREDENTIALS, and passing
    Unix sockets (this needs a cycle collector).
  - Full socket options, netlink route and loopback.
- **scheduling (7):** real affinity, the sched_* parameters and attributes, and ioprio.
- **mount (16):** mount/umount2, pivot_root, chroot, the new mount API, quotactl and mount
  namespaces.
- **system (31)**
  - Implemented: sysinfo, syslog, reboot, hostname, acct, swap, seccomp (filter mode), landlock,
    lsm, keyrings, and subsets of perf_event_open and bpf.
  - EPERM by policy wherever a microkernel cannot honour the call: kexec, modules, iopl/ioperm.

## X3. What Linux programs assume beyond syscalls (alongside X2)

- **Loader**
  - Dynamic linking through PT_INTERP, shebang scripts, and setuid exec with AT_SECURE. Done in
    v0.27 (ADR 0010): PT_INTERP, PIE programs and the interpreter loaded and validated, shebang
    scripts. Missing: setuid exec (AT_SECURE is set when the effective IDs differ from the real
    ones).
  - A full auxv. Done in v0.27 (ADR 0010) except AT_SYSINFO_EHDR, which needs the vDSO.
  - A vDSO and ASLR.
- **TTY**
  - A line discipline and every termios ioctl.
  - Controlling terminals, sessions and job control.
  - `/dev/tty`, `/dev/ptmx` and devpts.
- **procfs, sysfs and devtmpfs laid out as Linux does:**
  - per-process: `/proc/[pid]/{stat,status,maps,fd,...}`
  - system-wide: `/proc/{meminfo,cpuinfo,...}`
  - `/sys/class` subsets
  - the standard `/dev` nodes
- **Credentials:** real, effective, saved and filesystem IDs, supplementary groups, and Linux
  capabilities.
- **Resource limits:** every RLIMIT_* enforced, and usage accounting.
- **Filesystems:** read-write ext4, a unified page cache, tmpfs on `/tmp` and `/dev/shm`, and real
  hard links on ramfs.

## X4. Verification (from v0.27, growing with X2)

- **Suites in the rootfs.** Cross-build LTP (`syscalls` and `open_posix_testsuite`) and musl
  libc-test into the rootfs.
- **Runner and CI gate.** `scripts/run-compat-tests.sh` boots QEMU and collects pass/fail results.
  A CI job gates on regressions, and the counts are published in `docs/compat/`.
- **Coverage tables.** Regenerate the coverage table every release, add one for arm64, and track
  partial semantics per syscall.
- **Application ladder.** The ladder above runs as CI smoke tests.

| Release | Content |
|---|---|

coverage table regenerated and the test pass counts recorded.
