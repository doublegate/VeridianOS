# VeridianOS system call numbers

Generated by `tools/compat/gen_syscalls.py` from `abi/syscalls.map`; do not edit.

254 calls: 187 use their Linux number and name (ADR 0009), 67 are VeridianOS calls numbered from 1024 on every architecture. RISC-V and AArch64 use Linux's generic table (`abi/linux/syscall.tbl`), which leaves 28 of these calls to user space on RISC-V and 27 on AArch64 (`--`: open, fork and the like). C programs get the numbers from `<veridian/sysno.h>`, Rust programs from `userland/abi/syscall_numbers.rs`. What each Linux call implements, and how fully, is in `LINUX-SYSCALL-COVERAGE.md`.
